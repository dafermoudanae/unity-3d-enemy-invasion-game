# 3D Enemy Invasion Game (Unity)

A 3D shooter game built in Unity with C#. The player defends against waves of invading enemies.



## Project Structure

- `Camera.cs`: camera behaviour
- `ShooterController.cs`: player movement and controls
- `PlayerBullet.cs`: player projectiles
- `EnemiesMover.cs`: enemy movement
- `EnemyShooting.cs`: enemy firing logic
- `EnemyBullet.cs`: enemy projectiles
- `GameManager.cs`: game state and flow
- `groundCollision.cs`: ground collision handling
- `Shooter.obj`: 3D model of the shooter
- `assetsss.unitypackage`: Unity asset package used by the project

## How to Open

1. Install Unity and create a new 3D project.
2. In Unity, go to **Assets > Import Package > Custom Package** and import `assetsss.unitypackage`.
3. Copy the `.cs` scripts into the project's `Assets` folder.
4. Open the scene and press **Play**.
